# EverythingCrash
ASMを使用して全てのクラスの全てのメソッドにクラッシュさせるコードを注入するmodです。  
当然ゲームはクラッシュし、起動することはありません。注意して使用してください。

このModは、以下のMIT Licenseで公開されているコードの一部を使用しています。
- [TheTrialMonolith - GenericTransformer.java](https://github.com/kosianodanngoo/TheTrialMonolith/blob/master/src/main/java/io/github/kosianodangoo/trialmonolith/transformer/GenericTransformer.java)

また、上記のmodの設計を参考にしています。
